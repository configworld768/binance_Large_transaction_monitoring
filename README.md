# **🦉 4倍积分ALPHA Token Real-time Monitor (OWL 代币实时大单监控)**
## 本脚本适用于alpha交易赚取空投积分的玩家，实时监测4倍积分的alpah代币的流动性，在流动性比较好的时候告警，以便进行交易，降低交易损耗. ⚠️⚠️⚠️注：流动性充足的时候也是🐶庄砸盘的高峰期

[![视频描述](https://img.youtube.com/vi/8OBEdHj1b5w/0.jpg)](https://www.youtube.com/watch?v=8OBEdHj1b5w)

这是一个基于 Python 的轻量级加密货币监控脚本，专门用于监控 **Binance Web3 (Alpha Market)** 中 **4倍积分的AlPHA (ALPHA\_556USDT)** 代币的实时成交记录。

它通过连接 WebSocket 接口，实时分析每一笔交易，当监测到**连续的大额买单/卖单流**时，通过**钉钉机器人 (DingTalk)** 发送报警通知。

## **✨ 主要功能**

- **实时低延迟**: 直接连接 Binance Web3 WSS 接口 (nbstream.binance.com)，毫秒级获取数据。
- **智能策略监控**:
  - **连续性检测**: 能够识别“连续 N 笔交易均为大单”的异常交易流（通常意味着主力扫货或砸盘）。
  - **自定义阈值**: 可配置单笔数量门槛（如 500k）和连续笔数（如 30笔）。
- **钉钉报警**: 集成钉钉自定义机器人（支持加签安全设置），第一时间推送到手机。
- **防骚扰机制**: 内置冷却时间 (Cooldown)，防止行情剧烈波动时消息轰炸。

## **⚙️ 配置说明**

在使用之前，请打开 app.py 文件，并根据你的需求修改顶部的配置区域。

**⚠️ 安全警告**: 请勿将包含真实钉钉 ACCESS\_TOKEN 和 SECRET 的代码提交到公开的 GitHub 仓库！建议使用环境变量或将配置文件加入 .gitignore。

### **核心参数配置**

\# \--- 报警策略配置 \---

\# 单笔数量门槛: 只有大于此数量(OWL)的订单才会被计入  
SINGLE\_ORDER\_THRESHOLD \= 500000

\# 连续笔数门槛: 必须连续出现多少笔大于上述门槛的单子才报警  
\# 例如：设置为 30，表示必须连续 30 笔交易都大于 500k 才会触发报警  
CONSECUTIVE\_LIMIT \= 30

\# 报警冷却时间 (秒)，防止满足条件后一直刷屏  
ALERT\_COOLDOWN \= 60

### **钉钉机器人配置**

你需要创建一个钉钉群自定义机器人，并开启“加签”安全设置。

1. 打开钉钉群设置 \-\> 智能群助手 \-\> 添加机器人 \-\> 自定义。
2. 安全设置选择 **“加签”** (SEC...)。
3. 复制机器人的 Webhook 地址中的 access\_token 和加签的 Secret。

\# \--- 钉钉配置 \---  
DINGTALK\_ACCESS\_TOKEN \= "你的\_ACCESS\_TOKEN"  
DINGTALK\_SECRET \= "你的\_SEC\_开头密钥"

## **🧠 策略逻辑详解**

本脚本不使用简单的“时间窗口总和”逻辑，而是采用更严格的**连续性检测**：

1. 程序维护一个计数器 current\_consecutive\_count。
2. 每收到一笔 WebSocket 推送：
  - 如果 交易数量 \> SINGLE\_ORDER\_THRESHOLD，计数器 \+1。
  - 如果 交易数量 \<= SINGLE\_ORDER\_THRESHOLD，计数器**立即归零**。
3. 当计数器达到 CONSECUTIVE\_LIMIT (如 30\) 时，触发报警。

**为什么这样设计？**

这种策略能有效捕捉高频交易机器人的**拆单行为**（例如将一个大单拆成几百个 500k 的小单连续买入），这通常是流动性极佳、磨损极小的最佳交易窗口。
